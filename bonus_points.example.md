business-earned bonuses must be used for business purposes and reported to the
Reisestelle.

**Workflow:**

1. After each trip, fill the `bonusprogramme:` block in that trip's `trip.md`.
2. Add a row to the matching table below.
3. When a batch is reported, set `gemeldet_an_reisestelle: true` in those
   `trip.md` files and put the report date in the "Reported" column here.
